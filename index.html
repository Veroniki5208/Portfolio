What I actually believe

The problem is almost never what it first looks like

I've learned not to trust the first framing. The real insight is usually deeper, which is why I spend more time in Discover than most people think is necessary.

Clarity over cleverness. If someone has to think about how to use it, the design isn't done yet. I optimize for the person who's distracted, rushed, or confused — because that's a state everyone's been in.

"It launched" and "it worked" aren't the same thing. Shipping isn't the finish line. I want to know if what I made actually helped someone — which means deciding what success looks like before I start designing, not after.
